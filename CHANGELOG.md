# Changelog

## 0.1.0 — 2026-09-28

- Added a local desktop editor for Roblox R6 and R15 body animation.
- Added timeline keyframes, markers, playback, pose editing, undo/redo, and
  `.rbanim` project save/open.
- Added a localhost bridge and Roblox Studio plugin to import animation
  `KeyframeSequence` data without replacing existing local sequences.
- Published and verified the `ThrowRock` R15 asset
  (`135657623288200`) and `ThrowRock R6` asset (`118009092366291`) in Studio.
- Added Windows x64 MSI and NSIS installers and the Rojo plugin model.
